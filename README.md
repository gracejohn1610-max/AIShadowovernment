# 🏛️ AI Shadow Government

An AI-powered civic intelligence platform connecting **citizens with government officials** and providing **AI-assisted policy analysis**.

🌐 **Live Website:**
https://aishadowgovernment.onrender.com

## ✨ Features

* 👤 Citizen registration & login
* 📝 Submit civic complaints
* 📍 Locations & image uploads
* 🏛️ Government complaint management
* 🤖 AI-assisted complaint analysis
* 📋 Gemini-powered policy analysis
* 📊 Complaint prioritization & categorization
* 🔄 Complaint status tracking

## 🛠️ Tech Stack

**Python • Flask • SQLite • Google Gemini AI • HTML/CSS • Gunicorn • Render**

## 🎯 Goal

To make citizen-government communication **faster, smarter, and more transparent** using AI while keeping humans responsible for final decisions.

**Live:** https://aishadowgovernment.onrender.com
